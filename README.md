# MBU Digital Library

## Open the public site

The site is publicly available at:

https://tcharitha22.github.io/Digital-Library-Management-System/

The `http://127.0.0.1:5500/` address is a local preview and can only be opened on the computer running the preview server.

This is a public site. All files in this repository that are deployed—including the student profile, photo, resume, and library materials—can be viewed by anyone.
