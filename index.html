      Project overview

      About the MBU Digital Library

      A walkthrough of the project, its purpose, design, and features.

      The MBU Digital Library is a student-focused academic website designed to organize learning resources, assignments, and other educational materials in one place. It provides CSE (Data Science) students with a clear dashboard for finding and managing their learning materials.

      How the project is organized

      Key steps and features represented in the website.

      1

      Project Planning

      The project brings common academic needs together: modules, study materials, lab work, assignments, quizzes, projects, and references.

      2

      Design and Theme

      A dark navy and purple palette, white cards, rounded corners, simple icons, and soft borders create a consistent, readable interface.

      3

      Header and Identity

      The header displays the MBU logo, library title and tagline, current page, page search, a notifications control, and student profile context.

      4

      Sidebar Navigation

      The sidebar links to the dashboard, modules, My Learning, lab experiments, tools, study materials, references, assignments, quizzes and tests, projects, academic profile, and this project overview.

      5

      Welcome Banner

      The dashboard welcome area introduces the Data Science library and directs students to its academic content.

      6

      Quick Access

      Six dashboard cards provide working shortcuts to lab experiments, tools, references, study materials, assignments, and projects.

      7

      Student Identity

      A student profile card presents the student context and course information in one place.

      8

      Faculty Information

      A separate faculty card displays BosuBabu and the designation Assistant Professor.

      9

      Academic Profile

      The dashboard link opens a dedicated academic profile page with student, course, faculty, university, resume, and GitHub details.

      10

      Module Management

      Module 1 includes five bundled PDFs that open in an offline two-page flipbook. Tap a page or drag it across the book to turn pages; keyboard and navigation controls are also available.

      11

      Testing

      Verify navigation, page search, module uploads, submodule entry, links, images, and responsive layouts before presenting the site.

      Technologies in this implementation

      This project is a static, browser-based website.

      TechnologyPurpose
      HTMLDefines the page structure, navigation, and academic content.
      CSSStyles the layout, dark navy and purple theme, cards, and responsive views.
      JavaScript and PDF.jsControl navigation, search, module interactions, and the two-page PDF flipbook, which renders the bundled PDFs locally.
      Browser local storageStores profile, module, project, and uploaded-file data in the current browser; this static version has no server database.

      Before presenting

      Run through these checks in the browser.

      • Open each navigation item and all six quick-access cards.
      • Search for a visible item on the current page.
      • Add a module file and check its link.
      • Add a submodule and refresh to confirm it is saved.
      • Open each Module 1 PDF, tap or drag a page to turn it, and confirm both pages in each spread.
      • Upload a file to each learning area and confirm it persists after refresh.
      • Open the academic profile link and confirm its links work.
      • Check layout on a narrow screen.
      • Confirm profile and faculty details are accurate.

      Short presentation summary

      “My project is the MBU Digital Library, designed to give CSE (Data Science) students one place to access and organize academic resources. The dashboard includes a welcome banner, navigation, six quick-access cards, and student and faculty information. Students can browse course modules, add module files and subtopics, upload learning materials, manage lab experiments and projects separately, and view an academic profile. The interface combines a dark navy and purple theme and is built with HTML, CSS, and JavaScript. Data is stored in the browser; this version does not use a backend database.”
